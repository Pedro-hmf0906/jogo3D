# Créditos

## Modelos 3D

Pacote **Space Kit (2.0)**, de **Kenney** (https://www.kenney.nl).
Licença: **CC0 1.0 Universal** (domínio público; atribuição não obrigatória, mas devida).
Texto da licença em `assets/models/LICENSE_kenney_space_kit.txt`.

| Arquivo | Uso no jogo |
|---|---|
| `craft_speederD.obj` | Nave do jogador |
| `craft_racer.obj` | Nave inimiga (a ser usada) |
| `meteor_detailed.obj` | Obstáculo (meteoro) |
| `rock_largeA.obj` | Obstáculo (rocha) |
| `rock_crystals.obj` | Obstáculo (rocha com cristais) |

Os modelos são lidos pelo leitor de OBJ próprio do projeto (`src/objLoader.js`).
